# Manuel Medina Fotografía

Portfolio en HTML, CSS y JavaScript, autocontenido y adaptable a móvil.

## Abrir
Descarga `1-index.html` y ábrelo con un navegador. `index.html` es la entrada del proyecto y abre ese archivo automáticamente. No requiere instalación, paquetes, API ni conexión para sus imágenes e interacciones.

## Estado
Vista previa privada pendiente de revisión. No activar GitHub Pages ni cambiar la visibilidad sin aprobación del propietario.

## Imágenes
Diez imágenes recuperadas del perfil de Instagram `manuelmedinaperez` a petición del propietario. Copias de hasta 640 px, no originales de alta resolución. Los títulos son descriptivos. Se conservan sin regenerar. Antes de una publicación definitiva conviene sustituirlas por originales y revisar autoría, selección y permisos.

## Diseño
Estructura inspirada en la referencia World In My Lens que facilitó el propietario. No se han reutilizado fotos, marca, contactos ni textos de ese sitio. Esta versión se hizo directamente en HTML, sin Stitch.

## Controles
Portada: anterior/siguiente. Galerías: filtros. Fotografías: visor con flechas y tecla Escape. Menú: inicio, galerías, mirada y contacto. Contacto enlaza al Instagram, no contiene un formulario de envío.
